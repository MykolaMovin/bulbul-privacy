## Які дані використовує застосунок і навіщо

Bulbul працює без реєстрації облікового запису. Застосунок використовує:

- **Аудіозаписи голосу**, які ви створюєте під час вправ, щоб прослухати власне мовлення та виконати самооцінку. Під час запису також обробляються його тривалість і рівень гучності для таймера та візуального індикатора.
- **Історію практики та прогрес:** виконані вправи й уроки, дати та час завершення, поточний урок, кількість виконань, серії днів практики та розрахункову тривалість занять. Ці дані потрібні для продовження навчання, статистики та відображення прогресу. Час у статистиці визначається за орієнтовною тривалістю вправ, а не за тривалістю аудіозапису.
- **Самооцінки:** обраний режим оцінювання, оцінки чіткості, темпу й упевненості або позначку «Я молодець», а також сформовану на їх основі пораду. Поради залежать від ваших оцінок; автоматичного аналізу чи розпізнавання записаного мовлення в цій версії немає.
- **Ваші вподобання:** цілі навчання, рівень комфорту, обраний ритм практики, улюблені вправи, тему оформлення та налаштування метронома — для персоналізації застосунку.
- **Налаштування нагадувань:** увімкнення, обраний час, стан дозволу на сповіщення та службові ідентифікатори розкладу — для локальних нагадувань про практику.
- **Службовий стан:** завершення початкового налаштування, переглянуті підказки, ідентифікатори занять і дані для відновлення незавершеного збереження результату — щоб коректно продовжувати роботу й уникати повторного зарахування практики.

Bulbul не запитує ім’я, номер телефону, адресу електронної пошти, контакти, геолокацію або платіжні дані для користування застосунком.

## Навіщо потрібен мікрофон

Доступ до мікрофона потрібен для запису вашого голосу після запуску запису у вправі. Застосунок запитує системний дозвіл перед записом. Ви можете відмовити або відкликати дозвіл у налаштуваннях пристрою; тоді запис голосу буде недоступний.

Bulbul не виконує фоновий запис. Якщо під час активного запису згорнути застосунок, він зупиняє запис та запускає видалення тимчасового аудіофайлу. Відкликання дозволу на мікрофон саме по собі не видаляє раніше створені дані.

## Де зберігаються дані та кому вони передаються

Аудіозаписи зберігаються в тимчасовому сховищі — кеші застосунку на вашому пристрої. Для прослуховування під час самооцінки може створюватися окрема тимчасова копія. Архіву записів у застосунку немає.

Прогрес, історія, самооцінки, вподобання та службові дані зберігаються в локальному сховищі застосунку. Доступ до нього обмежується засобами операційної системи.

У цій версії Bulbul немає власного сервера для даних користувачів, хмарної синхронізації, рекламних або аналітичних сервісів. Застосунок не надсилає записи, прогрес чи самооцінки розробнику або стороннім сервісам, не продає їх і не використовує для навчання моделей штучного інтелекту. Нагадування плануються на пристрої та показуються операційною системою.

Операційна система може окремо створювати резервні копії локальних даних або переносити їх на інший пристрій залежно від системних налаштувань. Зокрема, прогрес і налаштування можуть відновитися після перевстановлення. На Android файли кешу, де зберігаються поточні аудіозаписи, виключені зі стандартного автоматичного резервного копіювання. Резервними копіями керує системний сервіс, а не розробник Bulbul.

## IP-адреси та відвідування вебсторінки політики

У поточній версії мобільного застосунку Bulbul немає функцій збирання, зберігання або відстеження IP-адрес користувачів. IP-адреси не використовуються застосунком для аналітики, реклами або визначення місцезнаходження.

Якщо ви переглядаєте цю політику на GitHub Pages, постачальник хостингу GitHub реєструє та зберігає IP-адресу відвідувача з метою безпеки, навіть без входу в обліковий запис GitHub. Це відбувається під час відвідування вебсторінки та не передає GitHub ваші локальні записи чи прогрес із застосунку. Умови обробки, строки зберігання та права щодо цих технічних даних визначаються [політикою конфіденційності GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Коли та як видаляються записи

За штатної роботи застосунку:

- поточний запис видаляється після команди видалення, перед новим записом, при скиданні поточної практики або підтвердженому виході з активного запису;
- при завершенні вправи початковий файл видаляється після підготовки тимчасової копії для екрана результату, якщо така копія потрібна;
- копія для самооцінки видаляється після її закриття, збереження оцінки або виходу з екрана результату;
- при згортанні застосунку під час активного запису запускається його зупинка та видалення.

Після збою, примусового закриття або помилки видалення тимчасові файли можуть залишитися в кеші. Залишки копій для самооцінки застосунок очищає під час наступного запуску. Інші залишкові аудіофайли можна видалити очищенням кешу чи даних Bulbul у системних налаштуваннях Android або повним видаленням застосунку. Операційна система також може самостійно очищати кеш, зокрема коли бракує місця.

Видалення аудіозапису не видаляє збережений результат практики та самооцінку.

## Як довго зберігається прогрес і як видалити всі локальні дані

Для прогресу, історії, самооцінок і налаштувань немає автоматичного строку видалення: вони зберігаються для подальшого користування застосунком, доки ви не очистите його дані або не видалите застосунок.

Щоб видалити всі локальні дані на Android, відкрийте системні налаштування → застосунки → Bulbul → сховище та виберіть очищення даних / сховища. Назви пунктів залежать від пристрою. Очищення лише кешу прибирає тимчасові файли, але не видаляє прогрес. Також можна повністю видалити застосунок; на iOS слід вибрати саме видалення, а не вивантаження зі збереженням даних.

Після очищення даних буде втрачено локальний прогрес, самооцінки, улюблені вправи та налаштування. Розробник не має серверної копії для їх відновлення та не може віддалено видалити дані з вашого пристрою. Видалення локальних даних не означає негайного видалення системних резервних копій: ними потрібно керувати окремо в налаштуваннях відповідного сервісу.
